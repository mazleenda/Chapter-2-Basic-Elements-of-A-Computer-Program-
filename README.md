# Chapter 2 – Basic Elements of a Computer Program

Welcome to the **Chapter 2** repository for **MEC212 – Basic Computer Programming**.

This repository provides practical exercises and example programs to help students understand the fundamental building blocks of Python programming. Students are encouraged to complete all exercises using **Google Colab** or **Thonny IDE** before referring to the suggested solutions.

## Learning Outcomes

Upon successful completion of this chapter, students should be able to:

1. Apply a systematic problem-solving approach to solve basic programming problems.
2. Construct algorithms using **pseudocode** and **flowcharts**.
3. Apply fundamental programming concepts, including:
   - Identifiers, variables, constants, and reserved words
   - Basic data types
   - Arithmetic operators and mathematical expressions
   - Assignment statements
   - Input and output statements
   - Predefined (built-in) functions
   - Introduction to programming control structures

## Software Requirements

- Python 3
- Google Colab
- Thonny IDE
